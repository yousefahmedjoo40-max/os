# ماين كرافت في BaridOS

اللانشر المرفق هو **PrismLauncher** (مفتوح المصدر وقانوني 100%) — لازم تسجل دخول
بحساب Microsoft/Mojang الرسمي عشان تنزّل اللعبة، لأن ماين كرافت نفسها ملك Mojang
وممنوع قانونياً تُوزع داخل أي ISO.

## التشغيل
من **لوحة BaridOS** اضغط زرار "ماين كرافت" — أول مرة هيثبت PrismLauncher تلقائياً
من Flathub، وبعدها يشتغل.

## إعدادات الأداء والتبريد (محطوطة افتراضياً)
- MangoHud شغال مع كل إصدار تضيفه في Prism: overlays للحرارة والفريمات.
- الـ FPS Limiter بتاع لوحة BaridOS بيتحكم في كل الألعاب من مكان واحد.
- وضع الأداء (performance) في التبريد بيرفع المراوح قبل ما الجهاز يسخن.

## إضافة نسخة (Instance)
1. Add Instance → اختر الإصدار (مثلاً 1.21)
2. من Settings بتاع الإضافة: Evironment Variables أضف:
   `MANGOHUD=1` عشان الـ overlay يشتغل
